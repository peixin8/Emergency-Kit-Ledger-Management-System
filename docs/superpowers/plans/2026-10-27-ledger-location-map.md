# 台账精确点位实施计划

> 前后端分别按仓库 Agent 规则实施；主 Agent 集成验证和提交。

**目标：** 在厦门地图上逐台显示已设置坐标的应急宝台账，并让用户为未定位台账选点。

**依据：** [设计文档](../specs/2026-10-27-ledger-location-map.md)。

**约束：** Java/Spring Boot + Vue 3；旧数据与旧 Excel 模板保留；经纬度以可空十进制字符串传输；不推测已有地址的精确位置。
