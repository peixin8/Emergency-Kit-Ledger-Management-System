# Excel 导入真实变化识别

现状：同编号 Excel 行即使与数据库业务字段完全相同，也会更新版本、更新时间并写一条内容相同的 UPDATE 历史，同时界面报告“覆盖”。本机 11 行导入文件与数据库一致，最近 11 条 UPDATE 的业务字段前后无差异，造成用户以为导入没有真实覆盖。

导入继续按台账编号匹配。新编号新增；已有编号仅在任一业务字段经现有入库规范化后确实不同才完整覆盖、增加版本及 UPDATE 历史。完全相同的行记为“无变化”，不改版本、更新时间、历史。空白字段清除旧值属于真实变化；功耗和坐标的等价数值表示不应产生伪变化。重复编号、已删除编号和无效文件仍按原规则整批回滚。

成功响应在原有 `importedCount`、`createdCount`、`updatedCount` 外增加 `unchangedCount`。`importedCount` 继续代表 Excel 中有效处理行数，等于新增、覆盖、无变化之和；页面显示三类数量，不把无变化称为覆盖。旧模板缺列继续按空值覆盖。使用隔离数据库测试，不重导用户文件到共享数据库。
