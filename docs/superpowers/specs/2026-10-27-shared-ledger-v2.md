# 共享台账 V2 设计

用户确认：无需登录；既要局域网网页共用同一数据库，也要 Excel 文件导入导出；“历史台账”仅指编辑修改记录。

## 数据与历史

- `emergency_device_ledger` 保留当前值；不改已执行的 V1 迁移，不覆盖用户现有数据。
- `ledger_audit` 已与创建、更新、软删除在同一事务保存完整前后快照。历史页读取此表，按 `created_at DESC,id DESC` 排序，包括已软删除的台账。
- `GET /api/v1/ledgers/{id}/history?page=1&pageSize=20` 返回 `{records,total,page,pageSize}`。每条记录含字符串 `id`、`ledgerId`，`action` 为 `CREATE|UPDATE|DELETE`，`occurredAt` 为带时区时间，`before`、`after` 为台账快照或 null。不存在的 ID 返回 404。
- 历史只读；无登录后操作人统一显示“共享用户”，不冒充可识别的个人。

## 共享与接口

- 访问前端直接进入 `/ledgers`，旧 `/login` 重定向；后端台账、历史和文件接口无需令牌。所有访问者共享同一数据库和增删改权限，删除仍为软删除并确认。
- 后端为审计保留数据库中的固定共享账号及默认新建组织，保证旧审计外键有效。共享页面读取所有既有组织的台账；修改和删除沿用目标记录的原组织归属，新建使用默认组织。旧表与现有记录保留，不迁移旧数据。
- 局域网启动时前后端监听局域网接口，前端 `/api` 代理指向本机后端。使用者通过运行机器的内网 IP 与前端端口访问。匿名可写服务仅用于受信任局域网。

## Excel

- `GET /api/v1/ledgers/export?keyword=&status=&direction=` 下载当前未删除记录的 `.xlsx`；列名是中文业务字段，包含唯一台账编号和设备信息，不把数据库 ID 当作导入身份。
- `POST /api/v1/ledgers/import` 接收 multipart `file`，仅追加新编号，不覆盖已有台账；返回 `{importedCount:number}`。按同一列格式导入，沿用现有必填、枚举、IP、VLAN、功耗及地址校验。重复/非法值指出行号；空表、超限或错误文件拒绝。整文件事务全成或全退；每行写 CREATE 审计。
- 前端提供下载、选文件导入及错误反馈，导入成功后刷新列表；用户可先导出作为模板。

## 验收

- 无登录直接查询、新建、修改、软删除；不同浏览器读取同一数据库。
- 修改前后快照在历史中完整展示，删除后历史仍可读取。
- Excel 下载可打开、导入往返一致，重复/非法/超限文件不发生部分写入。
- 后端 `mvnw.cmd verify`；前端类型检查、lint、测试、构建；运行中验证 HTTP 和页面。
