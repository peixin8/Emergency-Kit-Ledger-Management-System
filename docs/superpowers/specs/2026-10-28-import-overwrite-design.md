# Excel 导入覆盖设计

用户需要重复导入台账时覆盖现有信息，同时继续支持新设备导入。采用台账编号作为匹配键：同编号覆盖所有业务字段，包括空白单元格清空旧值；新编号新增并由数据库生成系统 ID。已删除台账的编号不能被覆盖或重新占用，须报出具体行号。文件内重复编号须报错，整份文件回滚。保留原有系统 ID、创建时间与历史记录，并为覆盖写入编辑历史。

接口 `POST /api/v1/ledgers/import` 继续接受现有的 `.xlsx` 模板，成功返回 `importedCount`（处理总数）、`createdCount` 和 `updatedCount`。页面显示新增/覆盖数量，并说明按编号匹配和空白值覆盖。单次导入沿用 2 MB、1000 行限制，任何行失败时不部分写入。

选择按编号覆盖而非按数据库 ID 覆盖，因为现有 Excel 模板没有系统 ID，且导出文件可以在不同数据库之间交换。也不采用“清空整个数据库后重建”：那会改变 ID 和破坏历史引用。所有验证使用隔离测试数据库，不把用户原始工作簿写入测试库或 Git。
