# 台账点位聚焦与导航

用户点击台账编号（例如 dsfg）后，应立即看到对应设备的具体点位，并可发起导航。沿用当前列表、首页地图和完整详情抽屉，不新增后端接口或数据库字段。

- 详情仍通过 `GET /api/v1/ledgers/{id}` 读取完整台账。坐标有效时，首页地图聚焦并放大至设备点位，详情抽屉顶部展示同一坐标的地图、目标地址和“高德导航”入口。地图点位及侧边列表点击进入同样的详情。
- 存储的坐标为 WGS84；高德导航 URI 使用 GCJ-02。只在生成导航 URL 时转换坐标，按官方 `https://uri.amap.com/navigation` 的 `to=经度,纬度,名称` 格式和参数编码构造链接；不向浏览器暴露 Web 服务 Key。
- 无坐标或坐标无效时，显示“尚未定位，请编辑选择目标地址点位”，不展示导航链接或虚构点位，首页地图保留原视野。请求失败或切换台账时不显示旧点位。
- 保留已有详情全部字段与编辑、历史、删除操作。前端先写失败测试，再实现；验证点击、切换、无坐标、导航坐标和链接安全，并运行前端全套及后端回归测试。完成本问题后单独提交。

依据：[高德 URI 路径规划文档](https://lbs.amap.com/api/uri-api/guide/travel/route)。
